# 🇺🇦 Поліглот 16: Англійська мова для українців

> **«Свобода перш за правильність: спочатку навчіться говорити і позбудьтеся страху, а правильність прийде з практикою!»**  
> *— Дмитро Петров*

Інтерактивний навчальний веб-застосунок та тренажер для вивчення англійської мови україномовними користувачами, створений на основі авторської методики 16 уроків поліглота Дмитра Петрова («Поліглот. Англійська за 16 годин»).

---

## 🌟 Особливості проєкту

1. **Адаптована теорія українською мовою (16 уроків у форматі Markdown)**:
   - Усі 16 уроків оригінального курсу перекладені та методично адаптовані для україномовних учнів (папка `content/`).
   - Наочні таблиці базової дієслівної матриці 3×3, правила узгодження часів, прийменники, фразові дієслова та словнички.

2. **Інтерактивна гра-тренажер (Q&A)**:
   - Перевірка знань після кожного уроку у форматі тестів з 4 варіантами відповідей.
   - Миттєвий зворотний зв'язок: зелене підсвічування при успіху, детальне пояснення правила українською при помилці.
   - Спеціальний режим **«Робота над помилками»** для повторення складних запитань.

3. **Інтерактивна Матриця Дієслова (3×3)**:
   - Окремий візуальний інструмент спряження дієслів: 3 часи (минулий, теперішній, майбутній) × 3 форми (ствердження, заперечення, питання).
   - Підтримка понад 14 популярних дієслів (*love, see, go, know, work, think, buy...*) та автоматична адаптація закінчень під будь-яку особу (*I, You, He, She, We, They*).

4. **Вимова та аудіо (Web Speech API)**:
   - Нативне браузерне озвучення англійських фраз та слів за кліком на значок 🔊 без сторонніх платних API.
   - Звукові ефекти правильних відповідей через Web Audio API.

5. **Гейміфікація та прогрес**:
   - Бали досвіду (XP) за правильні відповіді та завершення уроків.
   - Щоденний стрик (Streak 🔥).
   - Збереження всього прогресу в `localStorage` (без необхідності реєстрації).
   - Підтримка сучасної темної та світлої тем оформлення.

6. **Великий двомовний словник (5 600+ слів) та гра «Відгадай слово»**:
   - Повна база даних на основі історичного словника Др. Василя Лева та Івана Вербяного (`base/file.pdf`).
   - Двомовний повнотекстовий пошук: `🇬🇧 → 🇺🇦 Англо-український` та `🇺🇦 → 🇬🇧 Українсько-англійський`.
   - Алфавітна навігація за літерами латиниці (A–Z) та кирилиці (А–Я).
   - Нова інтерактивна гра на відгадування слів із 4 варіантами відповідей в обох напрямках (`EN → UA`, `UA → EN`, `Змішаний режим`).

## 🚀 Як запустити проєкт локально

Застосунок не потребує складного бекенду або встановлення важких пакетів. Достатньо будь-якого статичного веб-сервера:

### Варіант 1. За допомогою Python

```bash
python3 -m http.server 3000
```

Після цього відкрийте у браузері: [http://localhost:3000](http://localhost:3000)

### Варіант 2. За допомогою Node.js (npx serve)

```bash
npx serve .
```

### Варіант 3. Пряме відкриття

Можна просто двічі клікнути на файл `index.html` у вашому файловому менеджері та відкрити його в улюбленому сучасному веб-браузері (Chrome, Safari, Firefox, Edge).

## 🎓 16 Уроків курсу

1. **Урок 1**: Базова матриця дієслова (3 часи × 3 форми, правильні й неправильні дієслова).
2. **Урок 2**: Займенники (хто, кому, чий), питальні слова (5W), слова-двійники на -tion (-ція).
3. **Урок 3**: Дієслово *to be* (am, is, are, was, were, will be), прикметники, стани й професії.
4. **Урок 4**: Етикет, привітання, ввічливі фрази та перше знайомство.
5. **Урок 5**: Прикметники, ступені порівняння (-er/-est, more/most), прийменники часу (in/on/at).
6. **Урок 6**: Невизначені займенники (some, any, no, every) та правило одного заперечення.
7. **Урок 7**: Модальні дієслова (can, must, should, may) без часток *to*.
8. **Урок 8**: Тріада прийменників напрямку (to, in, from) та винятки множини іменників.
9. **Урок 9**: Зворотні займенники (-self / -selves) та розповідь про свій типовий день.
10. **Урок 10**: Зворот *there is / there are* у трьох часах та опис простору.
11. **Урок 11**: Конструкції наміру (*to be going to*) та необхідності (*to have to*).
12. **Урок 12**: Тривалий час (*Present Continuous*): процес прямо зараз проти регулярного факту.
13. **Урок 13**: Доконаний час (*Present Perfect*): зв'язок минулої дії з теперішнім результатом.
14. **Урок 14**: Пасивний стан (*Passive Voice*) та найуживаніші фразові дієслова.
15. **Урок 15**: Умовні речення (*First & Second Conditionals*): реальні плани та мрії.
16. **Урок 16**: Підсумки, зведення алгоритмів, поради для вільної розмови та фінальний іспит.
