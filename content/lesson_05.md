# Урок 5: Прикметники, ступені порівняння та час

> **Ключовий принцип Дмитра Петрова:**
> «Прикметники роблять мову барвистою. В англійській мові логіка порівняння гранично проста: для коротких слів додаємо хвостик, для довгих — ставимо слово "more".»

---

## 1. Ступені порівняння прикметників

### 1. Короткі прикметники (1-2 склади):
- Порівняльний ступінь: додаємо суфікс **-er** (*...ніший*)
- Найвищий ступінь: додаємо **the ... -est** (*най...ніший*)

| Базове слово | Порівняння (+ ніж / than) | Найвищий ступінь |
| :--- | :--- | :--- |
| **old** (старий) | **older** (старіший) | **the oldest** (найстаріший) |
| **young** (молодий) | **younger** (молодший) | **the youngest** (наймолодший) |
| **fast** (швидкий) | **faster** (швидший) | **the fastest** (найшвидший) |
| **big** (великий) | **bigger** (більший) | **the biggest** (найбільший) |

### 2. Довгі прикметники (3 і більше складів):
- Порівняльний: **more** + прикметник
- Найвищий: **the most** + прикметник

| Базове слово | Порівняння | Найвищий ступінь |
| :--- | :--- | :--- |
| **interesting** | **more interesting** (цікавіший) | **the most interesting** (найцікавіший) |
| **expensive** | **more expensive** (дорожчий) | **the most expensive** (найдорожчий) |
| **beautiful** | **more beautiful** (красивіший) | **the most beautiful** (найкрасивіший) |

### 3. Винятки (обов'язково запам'ятати!):
- **good** (хороший) → **better** (кращий) → **the best** (найкращий)
- **bad** (поганий) → **worse** (гірший) → **the worst** (найгірший)

---

## 2. Часові маркери та прийменники часу

Правило трьох прийменників часу:
- **AT** — для точного часу: `at 5 o'clock`, `at night`.
- **ON** — для днів тижня та дат: `on Monday`, `on Friday`.
- **IN** — для місяців, років, пір року та частин доби: `in May`, `in 2024`, `in summer`, `in the morning`.

### Дні тижня (завжди з великої літери!):
- `Monday` (понеділок), `Tuesday` (вівторок), `Wednesday` (середа), `Thursday` (четвер), `Friday` (п'ятниця), `Saturday` (субота), `Sunday` (неділя).
