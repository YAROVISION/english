# Урок 10: Зворот there is / there are та розширення лексики

> **Ключовий принцип Дмитра Петрова:**
> «Коли ми хочемо сказати, що десь щось є або знаходиться (на столі книга, у місті багато парків), в англійській мові речення обов'язково починається зі звороту "There is" (для одного предмета) або "There are" (для багатьох).»

---

## 1. Схема there is / there are

- **There is** + іменник в однині:
  - `There is a book on the table.` — На столі лежить книга.
- **There are** + іменник у множині:
  - `There are three apples in the bag.` — У сумці три яблука.

### У трьох часах:
| Час | Однина (is / was / will be) | Множина (are / were / will be) |
| :--- | :--- | :--- |
| **Теперішній (Present)** | **There is** a problem | **There are** many questions |
| **Минулий (Past)** | **There was** a call | **There were** guests |
| **Майбутній (Future)** | **There will be** an event | **There will be** changes |

### Питання та заперечення:
- Питання: виносимо дієслово наперед:
  - `Is there any tea?` — Чи є чай?
  - `Are there any free seats?` — Чи є вільні місця?
- Заперечення:
  - `There is no time.` — Немає часу.
  - `There aren't any problems.` — Немає жодних проблем.

## 2. Словничок 10-го уроку

- `table` [ˈteɪbl] — стіл
- `room` [ruːm] — кімната
- `problem` [ˈprɒbləm] — проблема
- `question` [ˈkwestʃən] — питання
- `many` [ˈmeni] — багато (для злічуваних: *many friends*)
- `much` [mʌtʃ] — багато (для незлічуваних: *much water*)
- `a lot of` [ə lɒt əv] — багато (універсально)
